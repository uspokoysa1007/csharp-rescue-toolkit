# csharp-rescue-toolkit

Утилита экстренного восстановления системы и снятия вредоносных блокировок Windows на C# (.NET 8).

## Возможности
- **Снятие системных ограничений:** разблокировка Диспетчера задач (`TaskMgr`), редактора реестра (`Regedit`), командной строки (`CMD`), оснасток MMC и Панели управления.
- **Очистка IFEO (Image File Execution Options):** удаление перехватов `Debugger` и мониторов `GlobalFlag` для антивирусных и системных утилит.
- **Восстановление оболочки:** проверка и сброс ключей Winlogon (`Shell` -> `explorer.exe`, `Userinit`) и очистка `AppInit_DLLs`.
- **Восстановление файловых ассоциаций:** починка запуска `.exe`, `.bat`, `.cmd`, `.com`, `.lnk`, `.reg`, `.msi`.
- **Проверка цифровых подписей процессов:** обнаружение активных неподписанных исполняемых файлов через WinAPI `WinVerifyTrust` (поддержка каталогов безопасности и прямых сертификатов).

## Сборка
```bash
dotnet build -c Release -o releases
```

## Использование
```bash
./releases/csharp-rescue-toolkit.exe
```
Для быстрого автоматического применения всех исправлений:
```bash
./releases/csharp-rescue-toolkit.exe --all
```
